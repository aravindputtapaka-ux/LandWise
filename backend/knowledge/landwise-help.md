# LandWise help
LandWise estimates property prices and affordability using collected property evidence.
A saved search records the result at the time the search ran. It is not a live market quote.
Run a new property search to request an updated estimate.

# Price estimates
The estimated total price depends on the entered area and the normalized comparable price.
Price per square foot and total price are different quantities. Always check the displayed unit.
Confidence reflects the evidence available for the estimate; it is not a guarantee.
Historical annual prices describe past data. Forecast prices are model predictions, not guaranteed future prices.

# Affordability
Affordability estimates how much area or what property options a budget may cover.
Taxes, registration, brokerage, legal checks and development costs may be excluded.

# History and chat
Property search history and chatbot conversation history are separate.
Open History to view a property result and use Ask about this result to start a conversation about it.
The assistant uses the signed-in user's saved searches and operator-provided help documents.
It does not run a fresh valuation from a chat message. Use the estimator for a fresh search.
